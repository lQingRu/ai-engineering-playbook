# Git

Apply when reviewing, committing, or publishing changes.

## Owned policy

- Keep each commit atomic and preserve unrelated work. Review the candidate diff and its check results before committing.
- Obtain human approval for commit and publication actions under the [personal approval policy](../global/AGENTS.md).
- Follow the repository's commit, branch, and merge conventions.

## External guidance

Use the [Conventional Commits specification](https://www.conventionalcommits.org/en/v1.0.0/) where that convention applies. Use Matt Pocock's `pr` when preparing a PR description.

## Project decisions and verification

Establish the commit convention, integration branch, merge strategy, and required checks. Confirm the staged change matches the reviewed candidate and verify the resulting commit.
